# Content Strategy Planner

Produce a content calendar a solo founder can actually execute.

## Procedure

1. **Understand the business.** Read `strategy/context.md` from the
   workspace (who the customer is, what the product does, what converts).
   If absent, derive what you can from the user's input and write the file
   so the next run starts warmer.
2. **Find the demand.** Search the web for the questions the audience asks
   (forums, "people also ask", competitor titles). Collect ten candidate
   topics with evidence of interest.
3. **Prioritize.** Score each topic: relevance to the product, difficulty
   to rank or stand out, effort to produce. Keep the top eight.
4. **Build the calendar.** Write `strategy/calendar-<month>.md`: one row
   per piece — publish date, working title, format (post, thread, video
   script), target reader, the single message it must land, and a
   three-bullet brief.
5. **Hand off.** Each brief should be enough for the blog-post-writer
   skill to draft from without asking questions.

## Rules

- Eight pieces a month, not thirty. The calendar must survive contact with
  a founder's week.
- Every topic carries its evidence link. "It feels right" is not a source.
